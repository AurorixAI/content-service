# Golden set — эталон для метрик

Golden — это задачи, **вычитанные человеком глазами по бумажной/сканированной
странице учебника**. Против них считаются `task_recall` и `latex_ned`.

> **Golden нельзя генерировать пайплайном или моделью.** Эталон, полученный из
> той же системы, которую он проверяет, показывает не качество, а согласованность
> системы с самой собой. Только ручная вычитка.

---

## Файлы

```
src/eval/golden/
  G7.jsonl          ← эталон для 7 класса (создать вручную)
  G8.jsonl          ← эталон для 8 класса (создать вручную)
  _example.jsonl    ← образец формата, метриками НЕ читается
```

Имя файла = `label` прогона (`scripts/eval.py --class-level 8` читает `G8.jsonl`).
Файлы с `_` в начале игнорируются — это образцы, не данные.

## Формат — JSONL, одна задача на строку

```json
{"paragraph": "12", "number": "142", "question_md": "Решите уравнение $x^2-5x+6=0$", "formulas": ["x^2-5x+6=0"], "answer_md": "$x_1=2,\\ x_2=3$", "page": 87, "note": ""}
```

| Поле | Обяз. | Смысл |
|---|---|---|
| `paragraph` | ✅ | Номер параграфа. **Ключ совпадения вместе с `number`** — одного номера мало, нумерация сбрасывается в каждом параграфе |
| `number` | ✅ | Номер упражнения ровно как в книге (`142`, `142а`, `1.15`) |
| `question_md` | ✅ | Условие дословно. Формулы — в `$…$` / `$$…$$` |
| `formulas` | — | Формулы списком. Если не задать — извлекутся из `question_md`/`answer_md`. Задавать явно, когда нужно проверить конкретные |
| `answer_md` | — | Ответ из книги, если он там есть |
| `page` | — | Страница скана — чтобы можно было перепроверить |
| `note` | — | Пометка для человека («битый LaTeX в оригинале», «кириллица в формуле») |

Строки, начинающиеся с `#`, и пустые — игнорируются, в них можно писать комментарии.

## Как вычитывать (инструкция человеку)

1. **Возьми ~20 задач на класс.** Меньше — метрики шумят, больше — долго вычитывать.
2. **Не бери подряд с одной страницы.** Нужен разброс: разные параграфы, разные
   типы задач (уравнение, текстовая, с чертежом, с подпунктами).
3. **Обязательно возьми страницы, где извлечение спотыкается.** Golden из одних
   чистых страниц бесполезен: он покажет 1.0 и ничего не поймает. Бери то, где
   в банке видны кривые формулы, пропущенные номера, склеенные задачи.
4. **Пиши то, что видишь на бумаге, а не то, что в базе.** Смотреть в
   `tasks_master` во время вычитки — значит скопировать туда её же ошибки.
5. **LaTeX пиши в естественной форме.** Косметика (`\dfrac` vs `\frac`, пробелы,
   `\left(` vs `(`) не штрафуется — её снимает канонизация (`src/eval/canonical.py`).
   Не подгоняй запись под то, как пишет модель.
6. **Нечитаемое в оригинале** — пиши `[unreadable]` и объясни в `note`. Не угадывай.
