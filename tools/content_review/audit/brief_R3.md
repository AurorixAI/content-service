# R3 — Независимый проверяющий (Sonnet)

Вход: `specs/fix_ctrl{W}.py`, `specs/split_x{W}.py`, `deact_w{W}.json` и исходные задачи из `audit/batch_*.json` (ищи по id). Рассуждения исправителя НЕ читай (`find_*`, `rejected_*` не открывать).
Для каждой правки независимо пересчитай (python3/sympy):
- новый ключ / новое условие — верно ли решение задачи с этим условием и ключом;
- каждый новый/изменённый дистрактор — не равен ключу; объяснение «Ученик …» при выполнении описанной ошибки даёт именно это значение;
- подзадачи разбиения — ключи верны, дистракторы неверны и объяснены;
- деактивация — задача действительно нерешаема по тексту.
Выход: `audit/verdict_{W}.jsonl` — по строке на задачу: `{"id": "...", "ok": true|false, "why": "одна строка (обязательно при false)"}`.
В чат вернуть ОДНУ строку: `verdict W: checked N, disagree M`.
